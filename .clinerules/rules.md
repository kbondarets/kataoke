# kataoke — коротко о главном

Полные правила — в `projectRules.md`. Замысел продукта — в `VISION.md`.
Карта репозитория и состояние — в `STATE.md`.

- **Источник истины по продукту — `VISION.md`.** Если код противоречит ему, сначала правим `VISION.md`, потом код.
- **Пользователь не разработчик.** Объясняем поведение, а не внутренности. Всё, что видит пользователь, — по-русски.
- **Ядро не знает про сервисы.** Любая привязка к Яндекс Музыке / YouTube живёт только в `src/adapters/<service>/`.
- **Позиция трека — только из `<video>`/`<audio>.currentTime`.** Прогресс-бар в DOM — запрещённый источник времени.
- **Оверлей — только в Shadow DOM.**
- **TypeScript strict, без `any`.** Стек: TypeScript + Preact + Vite, Manifest V3.
- **MVP без сервера и без ML в клиенте.** Тексты — LRCLIB. Alignment — задача v2 на сервере.
- **Никаких обходов DRM и модификаций чужого аудио.** См. `VISION.md` п. 6.1.
- **Перед «готово»:** `npm run check` — и ревью отдельным агентом по `.clinerules/workflows/review.md`. Автор себя не ревьюит.
- **Ветки:** `feature/<имя>`, `fix/<имя>`, `chore/<имя>` от `main`. Коммит: `<тип>: <описание>`.
- **Файл больше 250 строк — причина разбить. Больше 400 — блокирующее замечание.**
- **Если задача требует переделки соседнего модуля — сказать об этом до работы.**
